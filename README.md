Sums up Friday 20 November 2026's world news in one image. `main.py` (Python 3.13, standard library only) draws a 1024×1024 newspaper front page at run time — a teal masthead naming the day, a wide lead panel, four story panels and a wide closing panel: the Trump–Xi–Putin joint declaration from Shenzhen, Russia's strikes on Kyiv spilling into Poland, tankers burning in the Strait of Hormuz, the COP31 talks stalling over fossil fuels, Myanmar rejecting the World Court's genocide ruling, and Grand Theft Auto VI smashing launch sales records. Text is drawn with a built-in 5×7 bitmap font stored as integer bit rows, so the output is deterministic: two runs produce byte-identical PNGs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
